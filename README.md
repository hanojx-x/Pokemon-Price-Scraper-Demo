# Pokemon-Price-Scraper-Demo
A Python-based application that shows a list of prices for the first ten Pokémon sets, as well as other interesting statistics.

The Pokémon Price Scraper Demo sources its information from the website pricecharting.com.
- The Price Scraper's main menu is rather simple. First, make sure one of the ten sets from the dropdown is selected. If you would like to view a list of all of the cards in that set as well as their prices, select "View Prices". If you would like to view a list of statistics regarding the set, select "Set Statistics".
- View Prices will display a list of every single card in the selected set on pricecharting.com and their values. The prices shown correspond to ungraded, PSA 9 and PSA 10 grade cards. The searchbar allows for the selection of any specific card in the set and updates the list dynamically.
- Set Statistics will display the mean, median, minimum value, maximum value and number of each card listed on pricecharting.com that corresponds to the set. These statistics are displayed for ungrade and PSA 9/PSA 10 cards respectively. Additionally, there is another table that shows the top 5 most expensive cards in the set.
